# Markdown 文章使用说明

所有公开文章都放在 `content/posts` 文件夹中，一篇文章对应一个 `.md` 文件。

## 新建文章

1. 复制 `content/post-template.md` 到 `content/posts`。
2. 把文件名改成简短的英文地址，例如 `my-first-post.md`。
3. 修改开头 `---` 之间的文章信息。
4. 在第二个 `---` 之后使用 Markdown 写正文。
5. 重新发布网站，首页、归档、分类、标签、目录、站点地图和文章分享预览图会自动更新。

## 支持的正文格式

- 二级、三级标题
- 普通段落
- **粗体**、*斜体*、`行内代码`
- 链接与图片
- 有序和无序列表
- 引用
- 代码块
- 表格
- 分隔线

把 `draft` 设置为 `true` 可以暂时隐藏文章。
